The missing knowledge between AI agents and production Zcash.

Your AI agent is wrong about building on Zcash. zcashskills fixes that — each skill is a SKILL.md the agent reads before working. Works in Claude, Cursor, Codex, Devin, or any agent that can read a file.

Read https://zcashlabs.github.io/zcash-skills/SKILL.md and follow it before writing wallet code, touching shielded transactions, or shipping anything on Zcash.

Persistent setup

Codex
  1. Create AGENTS.md in your repo root
  2. Paste: Read https://zcashlabs.github.io/zcash-skills/SKILL.md and follow it before writing wallet code or shipping anything on Zcash.
Cursor
  1. Create .cursor/rules/zcashskills.mdc
  2. Paste a rule pointing at this repo's SKILL.md with alwaysApply: true
Claude Code / Devin
  1. Copy the whole skills/ tree into .claude/skills/ or .agents/skills/ — sibling layout is load-bearing (routers link ../other-skill/SKILL.md)
  2. Granular loading: only the skill whose description matches fires
Scripts
  1. Fetch https://zcashlabs.github.io/zcash-skills/SKILL.md and bake it into your pipeline or system prompt
